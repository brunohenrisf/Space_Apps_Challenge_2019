      Como usar

      Montando o programa

      • Arraste blocos da coluna da esquerda para a área do meio.
      • Comandos se encaixam um embaixo do outro; blocos arredondados (valores) entram dentro dos espaços dos outros blocos.
      • Só entra no código o que estiver dentro de ao iniciar (roda uma vez) ou repetir para sempre (roda sem parar).
      • Ao arrastar um comando, tudo que estiver abaixo dele vai junto.
      • Para apagar: arraste até a lixeira, ou selecione e aperte Delete.
      • Clique com o botão direito num bloco para duplicar ou apagar.
      • Arraste o fundo da tela para mover a área de trabalho.

      Gravando na placa

      1. Clique em Baixar .ino e abra o arquivo na Arduino IDE (ou cole o código com Copiar).
      2. Na IDE, instale o suporte ao ESP32 em Ferramentas → Placa → Gerenciador de placas → “esp32”.
      3. Selecione a placa (ESP32 Dev Module) e a porta COM/USB correta.
      4. Se o painel mostrar Bibliotecas necessárias, instale-as em Ferramentas → Gerenciar bibliotecas.
      5. Clique em Carregar. Se a gravação não começar, segure o botão BOOT da placa.

      core 2.x ou 3.x?

      O seletor core na barra de cima muda como o PWM e o buzzer são gerados. Veja a versão instalada em Gerenciador de placas → esp32: se começar com 3, deixe em 3.x; se começar com 2, mude para 2.x.

      Dicas de pinos

      • Os pinos 34, 35, 36 e 39 são só de entrada — não servem para LED.
      • Os pinos 6 a 11 são usados pela memória interna: não use.
      • A leitura analógica dos pinos ADC2 (0, 2, 4, 12–15, 25–27) não funciona enquanto o Wi-Fi estiver ligado; prefira 32–39.
      • O LED embutido costuma ser o pino 2.
